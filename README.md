# Library Manager API

API REST pour gérer une bibliothèque.

## Technologies

- Node.js
- Express
- MySQL
- Swagger pour la documentation de l'API

## Installation et lancement

1. Installer les dépendances avec `npm install`.
2. Configurer les paramètres de connexion et le secret dans le fichier `.env`, en s'aidant de `.env.example`.
3. En développement, lancer l'application avec `npm run dev`.
4. Pour un lancement normal, utiliser `npm start`.

La documentation Swagger sera accessible lorsque son interface sera configurée dans l'application.
